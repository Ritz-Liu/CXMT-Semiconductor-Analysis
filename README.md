# CXMT Semiconductor Analysis

## 半导体产业链股票分析项目

A semiconductor stock analysis project based on real market data, focusing on CXMT and global semiconductor peers.

一个基于真实市场数据的半导体股票分析项目，重点跟踪 CXMT 以及全球半导体产业链相关企业。


---

# Overview | 项目介绍

This project tracks the performance of semiconductor companies across different markets, including:

本项目跟踪不同市场中的半导体相关企业，包括：

- CXMT (ChangXin Memory Technologies)
- AMEC (Advanced Micro-Fabrication Equipment Inc. China)
- Apple
- NVIDIA
- SK Hynix
- Samsung Electronics
- Micron Technology


通过真实行情数据，对半导体产业链企业进行历史表现比较和可视化分析。


---

# Features | 项目特点

## English

- Real market price data collection
- Multi-market semiconductor stock comparison
- IPO performance tracking for CXMT
- Trading calendar aware visualization
- Historical return comparison
- No artificial price generation
- No forward filling of missing market data


## 中文

- 使用真实市场行情数据
- 支持多市场半导体企业比较
- 支持 CXMT IPO 后表现跟踪
- 根据不同市场交易日进行可视化
- 历史收益率对比分析
- 不生成模拟价格
- 不对缺失行情进行前向填充


---

# Data Policy | 数据原则

## English

This project follows a strict real-data policy:

- Missing trading dates are not filled artificially.
- Future market data is never generated.
- Non-trading days remain empty.
- Different market schedules are respected.

Missing data may occur because of:

- Market holidays
- Different exchange closing times
- Data availability timing


## 中文

本项目遵循严格的数据真实性原则：

- 不人为补充不存在的交易数据
- 不预测未来行情
- 不使用模拟价格
- 尊重不同交易市场的交易时间

数据缺失可能来自：

- 市场休市
- 不同交易所收盘时间差异
- 数据源更新时间差异
